# s15 — 最伟大的作品（Greatest Works of Art, 2022）·「还在流浪」· 公路旅行 · 复古明信片

## 要像
20 世纪中叶旅行明信片的一般风格（胶印插画 / 手工上色照片，不对应任何具体作品、封面或 MV 镜头）：
- **饱和但略褪色**的天蓝、橙、薄荷绿、奶油黄、珊瑚红；整体明亮，像晒过太阳的纸。
- **胶印网点**：天空、阴影面、车身暗部用规则的圆点网（15° 网角，点的大小随明暗变），近看是点、远看是色。
- **套色略错位**：色版相对细线版向右下错开约 2 单位，一侧露出一线纸白。细线版用深蓝灰，不用死黑。
- 四周一圈**白色明信片边**，角上微微磨损（掉色的白点、泛黄、一道折痕）；全画面一层很淡的纸色和颗粒（褪色感）。
- **招牌、路牌、车牌、邮票都不写字**：只用星星、箭头、灯泡、太阳和棕榈图案。

## 人物
场景内注册 `s15-postcard`：漫画化底层 → 手工上色照片的分档平涂：黑衣变成**褪色的靛蓝灰**（`#2f4c6e` / `#56799e`，暗部加细网点），皮肤桃色两档，外轮廓深蓝灰（不用死黑）；色版向右下错开 2px，错开处露出纸白（套色不准）。背景整体明亮，人物轮廓反差靠深色描边保证；必要时加纸白 `figureRim`。

## 梗怎么做
人物只定格（站立帧），不改人物本身。图章是场景里的矢量道具，落点 = 定格时人物胸口（`CHAR_X` + 站立帧胸口偏移）。邮戳预先烘焙成一张图（双圈、「2022」、星星、波浪线；再用 `destination-out` 打出漏印白点、按压不匀的渐淡和几处断口），在场景的 `drawFigure` 里先画人物、再按人物脚下原点叠印——所以它跟着人物走、跟着走路的前倾一起动，过画框时被画框边切掉。「一震、一凹」用 `figureAdjust` 和背景同步的平移 + 以落点为中心的微缩（0.98 → 1）实现。小邮戳和邮票印在「明信片表面」，固定在画面上。

## 标题卡、播放器、画框
- 标题卡：航空信封式——奶白卡面，外圈红 / 白 / 蓝斜条纹边，内框一道深蓝细线，角上一颗小星；文字深蓝灰，年份珊瑚红。
- 手机：薄荷绿机身（网点阴影、套色错位）、奶白屏幕；屏幕上是一圈会转的「太阳光芒」唱片（橙色，转起来看得见光芒在转）、珊瑚红进度条（随本站拍位往前走）、深蓝按钮。歌名底板是一张齿孔边的奶白邮票条，深蓝字（52px）。
- 离场画框（通往第 16 站）：明信片白边 + 邮票齿孔外沿，内沿一道深蓝细线和一道珊瑚红虚线，四角小星，右上角压一组波浪注销线。

## 亮度与反差（全局规则）
目标平均亮度 ≥ 60%（天空、白边、沙色路肩占大面积，柏油也是浅蓝灰）；人物轮廓反差 ≥ 3（深蓝灰描边对浅天空、沙色原野）。图章压下时画面里多一块木色，但只有半拍多。自查跑 `node tools/brightness.mjs --stations s15`。

## 约束
不画封面及近似版；不画 MV 镜头；画面只出现专辑名、歌名和邮戳上的「2022」（招牌、路牌、车牌、邮票都不写字）；播放器 / 加油站 / 汽车全部虚构、无真实品牌；司机等配角原创、不像任何真实人物；场景里不写死秒数、不用 `Math.random`（`npm test` 会查）。
