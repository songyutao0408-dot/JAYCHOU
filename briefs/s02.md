# s02 — 范特西（Fantasy, 2001）·「爱在西元前」· 古巴比伦城墙 · 两河流域浮雕

## 要像
两河流域的青金石釉砖墙与砂岩浅浮雕的一般风格：釉砖错缝、阶梯形雉堞、八瓣花饰带、侧身迈步的金色狮子；
浮雕人物侧脸配正面眼、筒形帽、编结胡须、长袍流苏、手捧供品。全部原创造型，不对应任何具体文物，也不对应 MV 画面。

## 人物
`relief`：砂岩色调 + 由轮廓推出的凹凸光影，像从墙上凿出来的一块。

## 节拍表
| 拍 | 发生什么 |
| --- | --- |
| 1 | 从描金画框（砂岩色）穿入 |
| 1–4 | 泥板标题卡、砂色磁带；浮雕队列每拍迈一步，和他同步；浮尘飘动 |
| 5–6 | 他定格成**正面站立**，浮雕里人人照样侧身走；第 5.6–6.6 拍离他最近的浮雕人**转成正脸、眼珠往他这边瞟** |
| 6.7–7 | 他被「压扁」成一条线（水平缩到 12%） |
| 7 | 弹回侧身，继续走 |
| 7–8 | 走向下一道画框 |

## 梗怎么做
- 正面站立 = 站立帧；压扁 = `figureAdjust` 返回 `sx`。
- 回头的浮雕人：在原位置盖一块底板，重画成 `frontal` 版本（正脸 + 眼白 + 偏左的眼珠）。哪一个人由 `env.camAt(第 5 拍)` 算出来，保证就在他右前方。
