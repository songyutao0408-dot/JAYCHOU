# s03 — 八度空间（The Eight Dimensions, 2002）·「爷爷泡的茶」· 山间茶棚 · 水墨

> 第三阶段第 1 批。建立水墨共用渲染 `src/kit/ink.js`（以后其他站可复用）。

## 要像
宣纸上的写意山水小品：大面积留白，远山用淡墨层层晕染（上浓下淡，山脚化进雾里），近处用枯笔皴擦、墨点苔点，
茅草茶棚和竹子用浓淡干湿不同的笔触。只用一点淡赭石（路、茶棚、老人的脸）和花青（远山）点缀，印章红只出现在标题卡、播放器和画框上。
只借一般水墨画风格，不对应任何具体作品、封面或 MV 镜头。

技法（全部在 `kit/ink.js`，Canvas2D 实现，预烘焙）：
- 宣纸：暖白底 + 低频云状斑驳 + 长纤维 + 稀疏杂点
- 晕染：多边形 + 竖向透明渐变 + 模糊滤镜（湿边），同一座山叠 2–3 遍、越往上越浓
- 枯笔：一笔由 6–12 根「笔毛」细线组成，按噪声断开（飞白），起笔重、收笔轻
- 苔点、墨点：噪声轮廓的小墨团 + 外圈晕开

## 人物
沿用 `ink`（`src/rig/styles.js`：三档墨色 + 晕开的边 + 毛笔描边），在宣纸底上已经够清楚，不另注册；
`figureRim` 加一圈宣纸色留白边（`#f7f3e8`，5px），保证走过中墨山坡、竹丛、茶棚竹竿时也拉得开。

## 原创配角：茶棚老人
简笔水墨造型：头顶一个小发髻、两道下垂的白长眉、一绺白胡子、闭着眼笑；淡墨宽袖布衣、浓墨腰带，微驼背，站在矮茶桌后面，面朝左（朝着他）。
手里一把提梁壶（壶嘴斜向上）。不像任何真实人物。

## 节拍表（每站 16 拍 = 4 小节）
| 拍 | 发生什么 |
| --- | --- |
| 1 | 从第 2 站的画框穿入山水（强拍，镜头轻推） |
| 1–4 | 宣纸标题卡、水墨磁带出现；雾带缓慢漂移，飞鸟掠过 |
| 5–8 | 往前走，茶棚从右边进画；第 6–8 拍老人把提梁壶高高举起，第 8 拍后半壶身一倾，茶水流出 |
| 9 | **强拍（第 3 小节）：茶水落地——落下的是一道墨线**，溅起一圈墨点、地上晕开一团墨 |
| 9–10.5 | 墨线沿地面蜿蜒向左，流到他（定格站立）脚下，脚下晕开一小团墨 |
| 10–12 | 墨线从落点向右延伸，铺过茶棚、伸出画面右边；老人一直在倒（桌上的茶杯始终是空的），第 11–12 拍收壶点头 |
| 13–16 | 他踩着墨线往前走，每一步脚下溅起几个小墨点；墨线一直在他前面，通向下一道画框（第 15–16 拍出现，卷轴裱框） |

## 梗怎么做
- 墨线是世界坐标里的一条固定路径（`ROAD_Y + 7` 附近微微起伏），用 `ink.js` 的 `inkRibbon` 一次烘焙成视差长条（p = 1）；每帧只按拍位裁出可见的那一段（左端、右端各一个「流动的墨头」）。
- 茶水：提梁壶嘴到落点的一条二次曲线，第 8.5–9 拍间壶嘴流出的墨头沿曲线下落，正好在第 9 拍强拍落地；倒茶时墨流微微摆动，第 11.5 拍收住、尾巴落下。
- 人物不动（定格是全局规则），只在第 13–16 拍每个拍点（落脚）画一圈小墨点。
- Outro 展墙定格在第 11.5 拍（`freezeBeat`）：墨线已经铺好，老人还在倒。

## 标题卡、播放器、画框
- 标题卡：宣纸卡片（毛边、淡投影）+ 枯笔方框 + 右上角一方印章红抽象纹样的印（无字）；文字焦墨，年份印章红。
- 播放器：水墨磁带——纸色壳、枯笔轮廓、淡墨标签区 + 小红印、浓墨转轮辐条照常转；歌名底板是一条宣纸签（枯笔边、红印点），歌名 52px。
- 离场画框：手卷裱框——淡青灰绫边（细云纹）、内外两道墨线和一道赭石细线，左右两端是深色木轴、上下伸出白玉轴头，一角钤一方小印。

## 亮度与反差
目标：每小节平均亮度 ≥ 70%（宣纸留白为主），人物轮廓反差 ≥ 3。中景山坡和竹丛在人物身后时，靠 `figureRim` 的宣纸色留白边保证反差。

## 约束
不画封面及近似版；不画 MV 镜头；画面只出现专辑名和歌名（茶旗、匾额都不写字，印章只用抽象纹样）；播放器全部虚构；场景里不写死秒数、不用 `Math.random`。
