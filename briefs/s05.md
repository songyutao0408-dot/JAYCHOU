# s05 — 七里香（Common Jasmine Orange, 2004）·「止战之殇」· 硝烟里的白鸽 · 黑白木刻版画

## 要像
黑白木刻：大面积墨色，靠刻刀刻出的浅色平行线表现明暗（越亮刻得越宽），物体边缘留一圈「让刀」。
灰纸黑墨，**整幅画没有纯白——唯一的白留给白鸽**。

## 构图
| 层 | 视差 | 内容 |
| --- | --- | --- |
| 天空 | 0.04 | 墨底刻横线，近地平线变亮；被硝烟遮住的太阳（一圈圈刻纹） |
| 硝烟 | 0.3 | 四根烟柱，每团烟从底部升起、变大、向右飘（按拍位推算） |
| 远景 | 0.3 | 残破的楼（锯齿断顶、空窗洞、断梁）、烟囱 |
| 中景 | 0.65 | 田野、枯树、沙袋墙、歪斜的铁丝网（三道下垂的线 + 刺） |
| 路面 | 1 | 坑洼土路、车辙、碎石、水洼 |
| 前景 | 1.3 | 蛇腹铁丝网、一顶头盔 |

## 调色板
墨 `#121110` · 纸 `#8f8a80` · 浅纸 `#b3ada1` · 纯白 `#ffffff`（只给白鸽）

## 人物
`woodcut`：黑白刀刻线 + 外缘一圈浅色「让刀」，和满是刻线的背景分开。

## 节拍表
| 拍 | 发生什么 |
| --- | --- |
| 1 | 从木刻画框（黑框 + 刻线）穿入 |
| 1–4 | 黑色印块标题卡；硝烟持续翻滚 |
| 3.2–5 | 白鸽从右上方划过天空飞来，最后半拍收翅 |
| 5 | **强拍落在他肩上**（正面站立，鸽子在肩外侧，先朝外、再转头朝前） |
| 7 | 他继续走，鸽子跳到走路时的肩背上 |
| 7.6–8.8 | 鸽子起飞，从下一道画框上方掠过、飞出画面 |

## 梗怎么做
鸽子在前景层画，位置挂在 `ANCHORS.stand.shoulder` / `ANCHORS.walk.shoulder` 上（`env.figure()` 给出人物位置）。

## 标题卡、播放器、画框
标题卡是木刻印出的黑色块，边缘有刻刀留下的浅色细线；磁带灰色、黑窗。画框黑色粗框 + 刻出的浅色细线。
