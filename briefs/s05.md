# s05 — 七里香（Common Jasmine Orange, 2004）·「止战之殇」· 废墟里的白鸽 · 铅笔速写 + 色彩晕开

> 第二阶段按用户要求重做（原为黑白木刻，太暗）。不再使用「刻线」共用渲染。

## 要像
浅米色速写纸上的浅灰铅笔速写，画面明亮、没有大面积暗色；颜色用水彩晕开的方式「长」出来。
铅笔线和水彩由 p5.brush 画（`2H` / `HB` 铅笔、`cpencil` 彩铅、`fill` + `fillBleed` 水彩），烘焙成视差长条；每帧的小物件用 `kit/sketch.js` 的手绘线。

## 构图
| 层 | 视差 | 内容 |
| --- | --- | --- |
| 纸 + 天空 | 0 / 0.05 | 米色速写纸，几笔铅笔云；晕开后天空是淡蓝 |
| 远景 | 0.3 | 断续的城市轮廓、窗洞 |
| 中景 | 0.7 | 炸断的墙（锯齿断顶、露砖、拱形窗洞、裂缝、钢筋）、倒下的路牌（只有箭头，没有字）；墙上的绿藤只在彩色里出现 |
| 地面 | 1 | 碎石路、裂缝、碎砖；废墟里的旧玩具熊（补丁、缝成叉的眼睛）；地上一顶侧倒的旧钢盔 |
| 前景 | 1.25 | 碎砖堆 |

定格时（第 9–12 拍）画面中间留出空地：钢盔在他右前方，玩具熊和路牌在右侧。

## 人物
`sketch`：纸色垫底 + 边缘线 + 暗部斜向排线 + 铅笔颗粒。颜色晕到他身上时淡入 `sketch-color`（淡彩：黑衣画成靛蓝色淡彩，上面仍是铅笔线）。

## 节拍表（每站 16 拍 = 4 小节）
| 拍 | 发生什么 |
| --- | --- |
| 1 | 从描金画框穿入（灰色速写） |
| 1–8 | 铅笔标题卡（贴胶带的纸片）、铅笔磁带；他每迈一步，前脚落地处的裂缝里冒出一朵小彩花 |
| 9 | **强拍（第 3 小节）：钢盔一晃，里面飞出一只白鸽**，颜色从钢盔处（画面中间）开始晕开 |
| 9–10 | 鸽子向右上方飞出画面，飞过的地方留下色团；主色团两拍内铺满全画面：墙上长出绿藤、天空变淡蓝、砖和玩具熊上色；人物同时淡入彩色 |
| 11–12 | 他站在彩色的画面里 |
| 13–16 | 他继续走向下一道画框，身后保持彩色，小花继续冒 |

## 梗怎么做
- 晕染区域 = 以钢盔为圆心、半径随拍位增大的噪声圆 + 沿鸽子路径的若干噪声圆（并集）；用它裁剪，按 `multiply` 叠水彩层；外圈再淡一层做羽化，主色团外缘描一道淡淡的积色边。
- 小花：每个走路拍点在 `env.camAt(拍) + CHAR_X + 92` 处冒出（世界坐标，跟着镜头走），第 9–12 拍定格时不冒。
- Outro 展墙定格在第 12 拍（`freezeBeat`），是已经上色的样子。

## 标题卡、播放器、画框
标题卡和歌名底板是贴了胶带的速写纸片（手绘双线框、右侧排线阴影），文字深灰 `#3b3732`，36px 以上；磁带是铅笔线稿，卷轴照常转动。画框是淡木色、铅笔双线。

## 亮度与反差
实测（`demo/2/brightness/`）：平均亮度 86%，人物轮廓反差最低 4.9。灰色速写阶段人物原本偏淡（反差 2.2），已把素描人物的外轮廓线加深、加粗。
