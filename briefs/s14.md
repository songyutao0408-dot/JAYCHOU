# s14 — 周杰伦的床边故事（Jay Chou's Bedtime Stories, 2016）·「前世情人」· 温馨的父女场景 · 童书绘本水彩

## 要像
整幅画是**绘本里的一页**：暖色水彩纸（`WC_PAPER.warm`）、柔和的湿画法、边缘积色、纸纹透出、彩铅细线勾边（暖棕、略抖、两遍叠线）。黄昏前的暖光：天空从淡粉紫渐到杏色、奶油黄，一轮低低的暖阳在山后发光；造型都圆润可爱（圆屋顶、棒棒糖树、气球一样鼓鼓的云）。
页边：画面四周不规则地晕开到纸白（绘本插图的「晕边」），左边一道很淡的装订阴影；底部正中「页码的位置」只画一个小月牙 + 两颗小星星的装饰，**不写页码数字、不写任何字**。
与第 10 站拉开：第 10 站是冷色蓝调雨夜、透明水彩、霓虹倒影、直线街景；这里是暖色白天 / 暖灯、笔法更软更圆、大量奶油色和杏色、彩铅勾边。

## 人物
`s14-wc`（场景里注册）：在 `watercolor-warm` 的基础上暗部用暖梅子色 `#4a3a4e`（黑衣保留透明感、不死黑），外面加一道暖棕彩铅细描边（1.6px），像绘本里给人物勾的线。背景很亮，不需要 `figureRim`。脚下一块淡淡的水彩投影。
**皇冠**：画在 `drawFigure` 里（在人物之后），定格时贴在站立帧头顶（`ANCHORS.stand.headTop`，按站立帧实测头顶微调）；走路时从每一帧走路图里量出头顶（最高的不透明像素 + 头部中线，帧间平滑），皇冠跟着头走，并随 `fig.lean` 一起前倾。皇冠下沿压在头顶下 22 单位处（盖住头顶的弧，不悬空也不穿头）。

**小女孩**（原创，约五六岁）：圆脸、两个扎着黄发带的小辫子、刘海、红扑扑的腮红、条纹衬衫外套珊瑚红背带裙（胸前小口袋上一颗心）、白袜、红皮鞋。代码画（矢量形状 + 每块积色边 + 彩铅勾线），先画进离屏再叠一层水彩颗粒。身高约 330 单位（他 500）。

## 第 14→15 站撕页转场（`transitionOut`）
`x` = 第 15 站的段内拍位（第 14 站 b = 16 + x），像素坐标。只用 `drawSceneLayers(ctx, envNext)` / `drawFigureFor(ctx, envNext)` 画第 15 站。
| x | 发生什么 |
| --- | --- |
| −2 … −1 | 照常画第 14 站（不出现画框） |
| −1 … 0 | 右上角翘起（折角的背面是纸背、带阴影），折角底下露出已经铺满的第 15 站；在 −0.5 拽一下；左上角靠装订处出现一道撕口，带白色纸纤维毛边，慢慢往下裂 |
| −0.06 … 0 | 撕口「刺啦」一下沿斜线一路裂到底 |
| 0（强拍） | 整页被「刷」地拽走：向右上缩走、略转，左边留下的一小条残边掉下去；人物在纸页范围内是旧画风、露出来的部分是第 15 站画风（按纸页轮廓裁切） |
| 后半拍 | 纸页对折（左半边翻过来，带透视和明暗）、再对折（下半边翻上来，露出背面的明信片格子线和邮票框，不写字），缩成明信片，转着飞进第 15 站的远处，变小消失 |

撕下后的时间按 `o.tail`（默认 0.4 拍 = 现有 `TAIL`）等比例安排；共用代码如果把这一站的转场尾巴延长到 1 拍并把 `tail` 传进来，折纸和飞走会自动放慢到约 1 拍（见汇报）。
实现：第 14 站在交界强拍那一刻（b = 16，不含人物）的画面画进离屏一次（缓存），切出撕口两侧的纸页正面、残边、纸背、明信片背面四张图；折叠时把翻折的一半按 20 条竖 / 横条带画（每条按翻转角做缩放和一点透视），先合成到半分辨率的纸页缓冲里再加明暗，最后按纸页的变换画上去。撕口毛边是 Canvas2D 路径（噪声 + 锯齿 + 白色纤维短线），不做逐像素处理。

## 标题卡、播放器、画框
标题卡：`wcCard`（奶白纸、杏色晕边、右下渗一点粉），四角各一颗彩铅小星星；字暖棕 `#5a3f3a`，年份 `#d9734e`，无强调竖条。歌名签同款小卡片。
播放器：绘本水彩画的手机——杏色机身（湿边积色 + 彩铅勾线）、奶油色屏幕；虚构界面：转动的圆盘（夜蓝底上一弯月牙和小星星——床边故事）、彩铅进度条（随本站拍位走，进度点是一颗小心）、上一首 / 播放 / 下一首三个圆角按钮。无 logo、无字。
离场画框：不用（第 14→15 站是撕页）。

## 亮度与反差（全局规则）
目标：平均亮度 ≥ 65%（暖色白天）；人物轮廓反差 ≥ 4（深梅子色人物 + 彩铅描边在亮背景前）。自查 `node tools/brightness.mjs --stations s14`。
