# s12 — 十二新作（Opus 12, 2012）·「红尘客栈」· 武侠客栈 · 木版年画

## 要像
杨柳青 / 桃花坞一类木版年画的一般风格（不对应任何具体作品、封面或 MV 镜头）：
- **粗黑木刻线**（主版）+ **平涂饱和色**（大红、桃红、明黄、翠绿、靛蓝），色版和线版**套色略有错位**（色块向右下偏 2–3 单位，一侧露出一线纸白、另一侧溢出黑线）。
- 纸是暖白 / 浅黄，有纸纹；色块上有一点**木纹和印刷不匀**的颗粒（`source-atop` 叠在已印的颜色上，纸面不脏）。
- 画面饱满喜庆：祥云、团花、回纹、角花；人脸圆、腮红两团。
- **酒旗、匾额、灯笼、对联都不写字**：酒旗是空白旗面 + 牙边，匾额是靛蓝底金边一朵团花，对联板只有金色回纹边。

## 人物
场景内注册 `s12-nianhua`：漫画化底层 → 四档平涂（墨黑 / 深靛 / 靛蓝亮面 / 肤色），黑线不动、色版向右下错开 2px，错开露出的缝填纸白（套色不准的味道），黑衣变成**靛蓝平涂 + 浅靛高光**，不是一整块死黑。外加一圈纸白描边 `figureRim`（年画人物外的留白），保证在红柱、靛蓝雨棚前也有反差。

## 原创配角（都是年画小人：圆脸、两团腮红、眯眼笑）
- **店小二**：瓜皮小帽（红顶珠）、翠绿短褂黄滚边、红腰带、黑裤白绑腿、黑布鞋，**右肩搭一条白毛巾**（两头蓝条），身高约 390 单位（大头）。不像任何真实人物或已有角色。
- **食客甲**：红脸膛络腮胡的壮汉，黑头巾、靛蓝袍；**食客乙**：桃红袍书生，方巾。
- **掌柜**：圆帽、八字胡、绛红袍，柜台上一把算盘。

## 节拍表（每站 16 拍 = 4 小节）
| 拍 | 发生什么 |
| --- | --- |
| 1 | 从第 11 站的画框穿入（强拍，镜头轻推） |
| 1–4 | 年画边框的标题卡、团花 CD 出现；街市：远山、城楼、粉墙、柳树、酒坛；灯笼每拍轻晃；客栈飞檐从右边进来 |
| 5–6 | 客栈门面整个进画（匾额、酒旗、灯笼、大堂里的食客和掌柜）；第 5.5 拍店小二从门里蹦出来（由小变大，像从屋里迈到街上） |
| 6–8 | 店小二小碎步迎上来（每半拍一跳，毛巾甩动）；第 8.5 拍刹住、往后一仰、两手张开蓄势 |
| 9 | **强拍（第 3 小节）他定格；店小二「啪」地抱拳作揖**：拳掌一合、身子猛地一躬，手边炸开几道黑色速度线 + 一圈明黄光芒 + 两朵小祥云 |
| 10 | 再深鞠一躬（每拍一次，躬落在拍上）；堂里两位食客起身拱手 |
| 11 | 再一躬；柜台后掌柜双手捧出一坛酒（红布封口，闪两颗小星） |
| 12 | 再一躬；他头边冒出一滴蓝色汗珠（定格的站立帧本身就够茫然） |
| 13–16 | 他继续走；店小二留在原地每拍一躬、慢慢退到他身后（他走过去以后店小二转过身，朝他的背影接着作揖）；食客坐回、掌柜还捧着酒；第 15–16 拍年画装饰边的画框（通往第 13 站蜡笔画）从右侧进来 |

代码里用 `GAG`（`src/beat/time.js`）表示这些位置，不写死秒数。

## 梗怎么做
人物只定格（站立帧），不改人物本身。店小二、食客、掌柜都是场景里的矢量年画小人：作揖 = 上身绕胯转一个角度（`bow`），每拍「快落慢起」；「啪」= 拳掌合上那一刻画速度线 / 光芒（0.6 拍内消散）。汗珠挂在 `ANCHORS.stand.headTop` 附近。店小二、客栈都按「定格时的画面位置」摆放（`env.camAt(GAG)`），第 13 拍后随世界一起往左退，正好落到他身后。

## 标题卡、播放器、画框
- 标题卡：暖白纸面，外圈大红边带上印明黄回纹，内外两道黑线，四角桃红团花；文字墨黑，年份大红。
- CD：浅黄盘面、大红色环上一圈黄点、中间一朵桃红团花（绿叶），转起来看得见花瓣在转；歌名底板红边黄心、墨黑字（52px）。
- 离场画框（通往第 13 站）：年画装饰边——外圈大红带明黄回纹、内圈翠绿细带、四角团花角花、上下边正中各一朵祥云，黑线勾边。

## 亮度与反差（全局规则）
目标平均亮度 ≥ 55%（实测 67%，最低 65%；轮廓反差最低 6.1，贴色 ≤ 1%）（年画本来就亮：纸白和明黄占大面积，红、靛只做点缀和结构）；人物轮廓反差 ≥ 3。他身后定格时是粉墙和纸白天空；酒旗、红柱可能在头边，用纸白 `figureRim`（宽 5）兜底。自查跑 `node tools/brightness.mjs --stations s12`。

## 约束
不画封面及近似版；不画 MV 镜头；画面只出现专辑名和歌名（酒旗、匾额、灯笼、对联都不写字）；播放器全部虚构；配角原创、不像任何真实人物；场景里不写死秒数、不用 `Math.random`（`npm test` 会查）。
