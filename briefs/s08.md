# s08 — 我很忙（On the Run!, 2007）·「最长的电影」· 老电影院 · 胶片划痕 + 4:3 画幅

## 要像
老电影的质感：胶片颗粒、竖向划痕（会跳、会断）、灰尘和毛发、偶尔的闪烁、片门轻微晃动、片头倒数式的圆圈小斑点（圆圈 + 十字线 + 扫过的扇形，不写数字）、换卷提示圆点。**发光的银幕占画面大部分**（亮），**观众剪影只在底部一窄条**。银幕里放的是一部原创的「无声黑白片」——一条浅灰调的老街，不出现任何真实电影画面或片名。

## 构图
「世界坐标」：银幕上的放映画面正好是 `x ∈ [X_MIN, X_MAX]、y ∈ [0, 1000]`（和普通场景单位一致）。镜头缩放 `Z`（中心 `CAM_A = [500, 250]`）：`Z = 1` 时银幕铺满画面，后退到底 `ZF = 0.84` 时银幕上沿在 y≈40、下沿在 y≈880。

## 人物
`film`：高反差灰阶、微泛黄；外加一圈很淡的暖白描边（`figureRim`，像老片的光渗）。`figureAdjust` 按镜头缩放给出 `scale / dx / dy`（再加上片门晃动），他始终「在银幕里」。定格 / 恢复走路按未量化的拍位切换，正好落在第 9、13 拍强拍。

## 量化
`quantize: 10`：人物取帧、颗粒、划痕、闪烁、片门晃动、观众小动作都按每秒约 10 次更新；镜头平移（`env.cam`）和镜头后退 / 推回不量化。硬切（4:3、扭头、定格）用未量化的拍位 `env.gb − sec.start`，不会因为量化晚一格。

## 节拍表（每站 16 拍 = 4 小节）
| 拍 | 发生什么 |
| --- | --- |
| 1 | 穿过第 7 站的画框进场，画面就是银幕里的黑白老街（铺满） |
| 1–4 | 标题卡、CD 出现；他在黑白片里走，划痕、颗粒、闪烁 |
| 5–8 | 镜头慢慢后退（`Z: 1 → 0.84`）：露出黑色遮幅、两侧红丝绒、顶上帷幔，观众剪影从下方升上来；银幕里一顶礼帽被风吹着从右往左滚过街面（次要小动作）；后排抱爆米花的观众每两拍往嘴边送一下 |
| 9 | **强拍**：画幅突然缩成 4:3（左右黑边带颗粒、毛边、一列会走的片孔），他在银幕里定格（站立帧） |
| 11 | **强拍**：两排观众同一帧扭头——后脑轮廓换成正脸（脸微亮、两只眼睛直直看向我们、眼镜反光、嘴一条短线） |
| 13 | **强拍**：画幅恢复 16:9，观众扭回去；他继续走 |
| 13–15 | 镜头推回银幕里（`Z: 0.84 → 1`），观众降出画面；第 14、15 拍右上角闪换卷提示圆点 |
| 15–16 | 离场画框（一格胶片画格）从右侧进来，进入第 9 站 |

## 标题卡、播放器、画框
- 标题卡：老电影字幕卡——黑底、细白双线边框、四角小菱形、上下边中间一小段装饰线；文字米白 `#f2ead2`（专辑中英名 + 年份）。
- 播放器：CD，米白盘面、灰阶，盘面上一圈像片孔的小方块（转起来看得出）；歌名底板同字幕卡样式，米白字。HUD 画在场景之后，不受 4:3 黑边遮挡。
- 离场画框：一格胶片——黑色片基、上下两排亮片孔、画格框线、片基划痕，右边还拖着下一格空画格。

## 亮度与反差
