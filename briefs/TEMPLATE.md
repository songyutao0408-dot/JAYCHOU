# sNN — 专辑（英文名, 年份）·「歌名」· 场景 · 画风

> 第三阶段子代理按这个格式写简报、按简报做 `src/scenes/sNN.js`。样例：`s02.md`、`s05.md`、`s09.md`。

## 要像
画风与技法要点（只借一般风格，不对应具体作品 / 封面 / MV 镜头）。

## 构图（从远到近，写视差系数）
天空 → 远景 → 中景 → 路面（`ROAD_Y = 800`，全片同高）→ 前景（定格时放在画面两侧，不挡人物）。

## 调色板
5–8 色，写 hex。

## 人物
`src/rig/styles.js` 里本站的画风名；需要时说明怎么调。

## 节拍表（每站 8 拍）
| 拍 | 发生什么 |
| --- | --- |
| 1 | 穿过画框进场（强拍，镜头轻推） |
| 1–4 | 标题卡、播放器出现；环境动态 |
| 5–6 | 梗（人物定格成站立帧） |
| 7–8 | 走向下一道画框 |

## 梗怎么做
只能对人物帧序列做整体平移 / 缩放 / 压扁 / 复制 / 局部放大，或在 `ANCHORS` 的点上挂东西。

## 标题卡、播放器、画框
`cardStyle.bgDraw`、`playerStyle`、`drawFrame` 的样子。

## 约束
不画封面及近似版；不画 MV 镜头；画面只出现专辑名和歌名；播放器 / 品牌全部虚构；场景里不写死秒数（`npm test` 会查）。
