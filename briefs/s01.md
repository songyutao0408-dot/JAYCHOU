# s01 — Jay（Jay, 2000）·「可爱女人」· 糖果色小镇 · 会动的贴纸

## 要像
糖果色的彩色插画：主色粉、天蓝、奶黄，天空是蜜桃色渐变，整体轻快甜腻，**像一张张会动的贴纸**——每样东西都有一圈白色贴纸描边和一点紫色投影（`bakeSticker` 预烘焙时自动加，动态小物用 `sticker()`）。
**主角是一架圆滚滚的玩具直升机**，第 1～4 小节都在画面里。杰伦全程留在地面，不坐进直升机；坐进机舱的是两个原创剪影（一男一女）。
街道、小店、招牌、橱窗全部原创，**不写字、不用品牌**（招牌只有爱心 / 星星 / 冰淇淋小图形）。不对应任何专辑封面或 MV 镜头。

## 人物
画风 `s01-candy`（在 `s01.js` 里 `registerStyle`）：`comicBase` 漫画化（深紫描线）→ 黑衣深发映射到深紫靛色阶（`#2a1d46 … #fff7ef`），皮肤映射到蜜桃色阶。
`figureRim: { color: '#ffffff', width: 4 }`：白色贴纸描边；刻意窄一点，让里面的深色轮廓线也贴着背景，轮廓反差更稳。
脚下一团紫色影子画在背景层（不算进人物）。不加任何新动作；第 4 小节的「缩成蚂蚁」只用 `figureAdjust` 的 `scale`（镜头处理）。

## 梗怎么做
- 他只是定格站立（共用结构），反应全靠环境：直升机、剪影、风、光、夜空。
- 直升机：机身是预烘焙贴纸（`heliBody`，2 倍分辨率），尾翼爱心、尾桨、主旋翼（模糊圆盘 + 两片桨 + 速度弧线）和舱里的乘客每帧画。位置 `heliAt(b)` 分段：跟随 → 绕圈 → 俯冲降落 → 升空 → 飞进银河 → 融化。
- 融化：先把直升机画进离屏图，再以起落架为锚塌成矮胖、按列加一点波浪，底下挂奶油滴和一摊，最后淡出；星河粒子从银河中心流出。
- 镜头拉远：`zoomAt(b)`（对数插值）。地面层缩放 Z，视差 p 的层缩放 `1 / (1 + p·(1/Z − 1))`（越远缩得越少），天空在无穷远不缩放；人物用 `figureAdjust → { scale: Z }`，锚点就是他的脚下。
- 树叶画在 `drawFigure` 里，挂在每一帧实测的头顶上；它在画面上的大小几乎不变，所以他一缩成蚂蚁，叶子就显得比他还大。
- 星座直升机：14 颗贴纸星（机身、尾巴、起落架、桨毂、两端在转的螺旋桨）+ 椭圆机身虚线 + 小脸，画在小镇前面，第 15 拍后慢慢往他头顶靠。

## 标题卡、播放器、画框
- 标题卡：奶油底 + 淡粉圆点、白色贴纸边、紫色投影、底部粉蓝两道色带，角上一颗爱心贴纸和一颗星星；字用黑体、深梅子色。
- 播放器：天蓝磁带，白色贴纸边，奶黄标签纸上两颗小爱心，粉色磁带卷在转；歌名放在粉白胶囊牌上（白边 + 粉色内描线），深梅子色 52px。
- 离场画框：粉色宽边 + 白圆点，白色贴纸边和紫色投影都是环形（不盖住画框里的下一站）。

## 亮度与反差（全局规则）
白天三小节预计 80% 以上。第 3 小节的深紫夜空用糖果色星云、亮银河、亮星河、亮着的窗户把亮度托住（夜景小镇只压暗约 36%）。
人物外面一圈白色贴纸描边，深色背景前反差也够。
实测（`node tools/brightness.mjs --stations s01`）：第 1–4 小节 84% / 84% / 76% / 84%，平均 82%；轮廓反差最低 7.0，贴色 0%，全部合格。
第 3 小节最暗的那一拍（全夜 + 银河，b=10.5–11.9）另测为 62%。
