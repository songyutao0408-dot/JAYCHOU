# s01 — Jay（Jay, 2000）·「可爱女人」· 青春街角 · 漫画网点分镜

## 要像
千禧年前后黑白少年漫画 / 少女漫画的一般画法：白纸为主，黑色钢笔线（粗外轮廓、细内线），灰面一律用**网点纸**（45° 圆点网，渐变网点表现天空和阴影），
动作用**速度线 / 集中线**，镜头切换用**分镜格**（黑框 + 白色格间距）。整幅画是一页漫画里的一格横幅大格。
街角道具全部原创、**不写字、不用任何品牌**：报刊亭（杂志只画色块与网点）、自动售货机（只画瓶罐剪影和按钮）、电线杆和电线、斑马线、樱花树、小店卷帘门和遮阳篷。
不对应任何专辑封面或 MV 镜头。

## 调色板
纸白 `#fbfaf6` · 墨黑 `#151515` · 深灰网点 `#3a3a3a` · 中灰 `#8a8a8a` · 浅灰 `#d6d6d2` · 纸影 `#ecebe6`
（全站只用黑、白、灰，灰色都用网点表现，不用彩色。）

## 人物
`halftone`（`src/rig/styles.js` 已有：灰阶 + 45° 网点 + 粗黑描边），不改。
外面加一圈纸白描边 `figureRim: { color: '#fbfaf6', width: 6 }`——漫画里人物压在网点或线条上时常用的「白边」，保证经过灰网点马路、售货机时也拉得开。

## 节拍表（每站 16 拍 = 4 小节）
| 拍 | 发生什么 |
| --- | --- |
| 1 | 从 Intro 的画框穿入（强拍，镜头轻推）；画面四周一圈**集中线**闪一下，0.6 拍内褪掉 |
| 1–4 | 网点标题卡（分镜格样式）和网点磁带 + 对话框歌名出现；樱花瓣一直在飘；镜头带过报刊亭（大叔在看一份没有字的报纸） |
| 5–8 | 往前走，经过自动售货机，**次要小动作：第 6 拍强拍，售货机自己「咚」地掉出一罐饮料**（出货口画两道冲击线），没人买；售货机顶上的猫目送他 |
| 9 | **梗：他一回头**——人物自动定格成正面站立帧；同一强拍上，背景**瞬间**换成少女漫画背景：中间留白、四周渐变网点，铺满玫瑰、小花、四角星闪光、泡泡、花瓣；闪光一闪一闪 |
| 10 | 强拍上**瞬间复原**成街角（硬切，像翻到下一格）；只剩一片花瓣慢慢飘过他眼前；右上角插入第一个小分镜格：等红灯的女生（原创，马尾、水手领）回过头来 |
| 10.5 | 他头侧冒出一颗漫画汗滴，慢慢往下滑 |
| 11 | 第二个小分镜格：报刊亭大叔从报纸后面回过头来，镜片反光 |
| 12 | 售货机顶上的猫也回过头（画面里，不进格子）；三格同时定住，一本正经 |
| 13 | 小分镜格滑出画面，汗滴消失，他继续往前走 |
| 13–16 | 走过樱花树和单车，走向下一道画框（第 15–16 拍出现漫画分镜框样式的画框） |

代码里用 `STATION`、`GAG`（`src/beat/time.js`）表示这些位置，不写死拍数。

## 梗怎么做
- 回头 = 第 9–12 拍人物自动定格的**正面站立帧**，不另做动作。
- 少女漫画背景：一张屏幕大小的预烘焙图（渐变网点、玫瑰、小花、泡泡、花瓣），只在 `b ∈ [GAG, GAG+1)` 盖住整个背景；
  上面叠几颗按拍位闪烁的四角星（动态，每帧只画十几个形状）。第 10 拍强拍硬切回街景。
- 汗滴挂在 `ANCHORS.stand.headTop` 旁边。
- 小分镜格画在 `drawFront`，固定在画面右上（不挡人物），每格在自己的强拍上「啪」地落下（0.12 拍缩放到位）；第 13 拍滑出。
- 猫的位置按 `env.camAt(GAG)` 算，保证定格时在他左后方的售货机顶上。

## 标题卡、播放器、画框
- 标题卡：一格漫画分镜——白底、粗黑框、右下硬投影（黑色错位块）、左侧一条网点竖条代替强调色条；字全黑。
- 播放器：黑白磁带，白壳黑线，标签纸贴网点，转轮旁两道漫画「转动」弧线；歌名放在**对话框**里（白底圆角气泡 + 黑描边 + 指向磁带的尾巴），黑色粗体 52px。
- 离场画框（进入第 2 站）：漫画分镜框——白色页边宽带、内外两道黑线、右下错位网点阴影，四周外侧几道速度线。

## 亮度与反差（全局规则）
目标平均亮度 ≥ 60%（白纸为主，预计 75% 以上）；梗那一拍的少女漫画背景同样以白为主（中间留白，网点只在四周）。
人物轮廓反差目标 ≥ 3：人物黑衣 + 粗黑描边，外面一圈纸白描边，背景以白为主。
自查：`node tools/brightness.mjs --stations s01 --out render/s01/brightness`。
实测：第 1–4 小节 80% / 79% / 78% / 80%，平均 79%；人物轮廓反差最低 12.9，贴色最多 5%，全部合格。

## 约束
不画封面及近似版；不画 MV 镜头；画面只出现专辑名和歌名（招牌、报纸、杂志、售货机都不写字）；播放器 / 品牌全部虚构；路人、大叔、猫都是原创简单造型；
场景里不写死秒数、不用 `Math.random`（`npm test` 会查）。
