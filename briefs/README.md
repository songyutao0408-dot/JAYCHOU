# 美术简报

第三阶段为其余 13 站各写一份简报（`briefs/sNN.md`），交给子代理按简报制作 `src/scenes/sNN.js`。
第二阶段精做的 3 站（第 1、11、16 站）也会补一份简报，作为其他站的写法样例。

每份简报至少包含：画风与技法要点、构图（前中后景）、调色板、人物帧序列在本站的画风处理（`src/rig/styles.js`）、梗里人物怎么动（只能用走路帧、站立帧做整体平移/缩放/复制/局部放大）、
标题卡与播放器的样式、第 2 小节的梗按拍拆解、需要用到的共用渲染（刻线 / 水墨 / 水彩）。

约束（所有简报通用）：不画专辑封面及其近似版；不画 MV 具体镜头和构图；画面只出现专辑名和歌名；
播放器、唱片公司、App 界面全部虚构；场景只按歌名和歌曲的大致主题原创设计。


已写好的简报：s02、s05、s09（已完成的站）；s04、s06、s07、s08、s10、s16（第二阶段后按用户要求先行确定的设计，第三阶段照此制作）。
每份简报都要包含「亮度与反差」一节（全局规则，见 PROMPT.md）。
