# s04 — 叶惠美（Yeh Hui-Mei, 2003）·「以父之名」· 白天的哥特教堂 · 彩色玻璃

## 要像
哥特教堂的彩色玻璃窗。**白天**：阳光透过彩色玻璃，在**浅色石墙和地面**投下彩色光斑；铅条描边**细**，不要太粗。整体明亮通透，不要大面积暗部。原创纹样，不对应任何真实教堂的窗。

## 构图
| 层 | 视差 | 内容 |
| --- | --- | --- |
| 远景 | 0.3 | 浅色石砌的尖拱长廊、高窗（彩色玻璃：几何花窗 + 抽象人物纹样，细铅条） |
| 中景 | 0.7 | 石柱、拱券；阳光从高窗斜射下来的光柱（带浮尘） |
| 地面 | 1 | 浅色石板地面，**彩色光斑**随镜头和光柱位置变化（落在地面和石墙上） |
| 前景 | 1.3 | 一排木长椅的椅背剪影（浅色木，不要黑） |

## 人物
`stained`（第三阶段调整为白天版：浅色底，彩色玻璃块只在他身上有光斑的地方出现，铅条细）。走过光斑时，彩色光落在他身上。黑衣在浅色石墙前反差足够。

## 调色板
石墙 `#efe9dc` / `#d9cfbd` · 铅条 `#3c3a44`（细，1.5–2px）· 玻璃 `#2f6fb0` `#c0392b` `#e8b54a` `#3f9a6a` `#7a4fa0` · 阳光 `#fff3cf`

## 节拍表（每站 16 拍 = 4 小节）
| 拍 | 发生什么 |
| --- | --- |

| 1–4 | 标题卡、磁带出现；他走在长廊里 |

| 13–16 | 他走出窗格，恢复原样，走向下一道画框 |

## 梗怎么做
「被切成彩色玻璃」：第 9–12 拍人物用 `stained` 画风（细铅条），其余时间用普通漫画化 + 光斑叠色。光束为叠加（lighter）的暖白梯形 + 浮尘粒子。

## 标题卡、播放器、画框
标题卡：浅石色卡片，四角细铅条花窗纹，文字深灰。磁带：浅色外壳，标签窗是一小块彩色玻璃。画框：浅石雕尖拱框。

## 亮度与反差
目标平均亮度 ≥ 55%；人物轮廓反差 ≥ 3（浅色石墙前的黑衣，正常即可达到）。
