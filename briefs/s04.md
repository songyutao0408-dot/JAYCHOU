# s04 — 叶惠美（Yeh Hui-Mei, 2003）·「以父之名」· 白天的哥特教堂 · 彩色玻璃

## 要像
哥特教堂的彩色玻璃窗。**白天**：阳光透过彩色玻璃，在**浅色石墙和地面**投下彩色光斑；铅条描边**细**，不要太粗。整体明亮通透，不要大面积暗部。原创纹样，不对应任何真实教堂的窗。

## 人物
- 平时 `s04-comic`（漫画化，暖一点的墨色）+ **光斑叠色**：走进光柱时，把光柱的玻璃纹样只画在人物轮廓里（先正片叠底染色、再相加提亮），彩色光从他身上滑过。
- 梗 `s04-glass`（本站注册的白天版彩色玻璃）：Voronoi 小块 + 细铅条（≈ 2px）；按部位配色像一扇设计过的人像窗——头发紫 / 深蓝，上衣蓝 / 青，裤子紫，鞋红 / 琥珀，脸和手是暖色浅玻璃，五官用赭色细线「彩绘」。
- 黑衣在浅色石墙前反差足够，不加轮廓光。

## 节拍表（每站 16 拍 = 4 小节）
| 拍 | 发生什么 |
| --- | --- |
| 1 | 从第 3 站的画框穿入（强拍） |
| 1–4 | 标题卡、磁带出现；他走在侧廊里，第 2、4 拍附近各有一道光柱扫过他 |
| 5–8 | 走过一扇扇高窗下，地面的彩色光斑和光柱从他身上滑过（约第 6 拍一道；第 7–8 拍巨大花窗的投影迎面而来，光柱扫过他的上半身） |
| 9 | **强拍**：他正好站进巨大花窗的投影里定格——**变成彩色玻璃**（细铅条切成一块块）；巨大花窗亮一下，地上的投影变亮 |
| 9–11 | 投影缓缓流转（光斑微微左移、明暗起伏）；他身上的玻璃 |
| 11 | （第 3 小节第 3 拍）**一束阳光从玫瑰窗直射下来，穿过他的胸口**：四周微微压暗，玻璃被照透（颜色变亮），暖金色浮尘闪成十字星 |
| 11.4–12.9 | 浮尘在他头顶聚成一圈，又散开（一本正经的小细节） |
| 13 | 强拍：恢复原样（漫画化），继续走出投影 |
| 13–16 | 走向下一道画框（浅石雕尖拱框，第 15–16 拍出现） |

阳光仍按原定放在第 11 拍：第 9 拍强拍已经有「变成玻璃」这个大动作，第 11 拍（小节内的次强拍）再来一束光，两个点分开更清楚。

## 梗怎么做
- `figureAdjust` 在第 9–12 拍返回 `style: 's04-glass'`；`drawFigure` 自己画人物：先 `drawWalker`，再用离屏画布把光柱纹样 / 白光 / 人物自身按人物轮廓遮罩后叠回画面（变身闪一下、阳光照透）。
- 巨大花窗按 `env.camAt(GAG)` 摆放：定格时它的中心在画面 x ≈ 585，玫瑰窗 → 他胸口的连线正好是全站的光线方向；它的地面投影在第 9 拍正好罩住他的脚下。
- 每道光柱按「哪一拍正好照到他」来摆放（`BEAMS` 的 `hit`），保证第 5–8 拍有光斑滑过他。
- 光斑纹样：把窗的纹样画成小图再模糊放大，边缘软、铅条只剩淡影；落在地面 / 墙面时先 `multiply` 染色、再 `lighter` 提亮。
- 浮尘在浅底上用暖金色小点 + 白芯（纯白相加在浅墙上看不见）。

## 标题卡、播放器、画框
- 标题卡：浅石色卡片，内圈一道细铅条线，四角是四叶小花窗（彩色玻璃 + 细铅条），角花之间细铅条花边；文字深灰 `#3c3a44`，年份蓝。
- 磁带：浅石色外壳；标签纸上沿一排小彩色玻璃；**窗口是一小块彩色玻璃**（铅条分块），磁带卷和转轮从后面透出来。歌名底板：浅石卡片，底边一条细彩色玻璃。
- 离场画框：浅石雕尖拱门框——石框四边（右下背光略暗）、框沿一圈细彩色玻璃、上角拱肩把开口做成尖拱（画框快铺满画面时收起）、拱肩里的四叶小窗、上方陡的山花（卷叶 + 尖顶饰 + 小玫瑰窗）、两侧小尖塔。
- Outro 展墙定格在第 11.8 拍（玻璃人 + 阳光 + 头顶的浮尘圈）。
