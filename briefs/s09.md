# s09 — 魔杰座（Capricorn, 2008）·「乔克叔叔」· 马戏团小丑 · 19 世纪石版画海报

## 要像
石版印刷的马戏海报：有限套色、色块与深蓝轮廓线故意错开 3px（套色不准）、点刻阴影、蜡笔颗粒。**海报上不放任何字**。

## 构图
| 层 | 视差 | 内容 |
| --- | --- | --- |
| 篷布 | 0.35 | 红白竖条纹（上窄下宽）、上暗下亮 + 点刻、荷叶边帷幔与流苏、两串三角彩旗 |
| 灯光 | 0.2 | 三道从顶上斜下来的探照灯光柱，缓慢扫动（叠加混合） |
| 观众席 | 0.55 | 四排剪影观众（偶尔有礼帽）、红色栏杆 |
| 柱子 | 0.92 | 深蓝缠芥末黄斜条的大柱 |
| 围栏 | 0.85 | 红色马戏场围栏、星星、条纹鼓凳 |
| 地面 | 1 | 木屑地面、一条白色场线 |
| 丑角 | 1 | 原创高个丑角「乔克叔叔」：白脸红鼻、尖帽、褶领、菱格裤、大红鞋，左手举一把气球 |

## 调色板
米白 `#efe0bf` / `#f4e8cc` · 红 `#d0533c` / `#a63a2a` · 深蓝 `#2b2a3a` · 青绿 `#2f7d6d` · 芥末黄 `#e2a93b`

## 人物
`litho`：深蓝、红、米白三色套印 + 颗粒。

## 节拍表（每站 16 拍 = 4 小节）
| 拍 | 发生什么 |
| --- | --- |
| 1 | 从海报边框（深蓝宽边、红线、星星）穿入 |
| 1–8 | 缎带标题卡；探照灯扫动；他穿过大棚，丑角出现在前方，每拍点一下脚 |
| 7.5–9 | 丑角伸手递出一只芥末黄气球 |
| 9 | **强拍（第 3 小节）他接住**（正面站立，气球线在右手，气球飘在头顶前上方） |
| 11.5–12.8 | 气球把他整个人带着飘起来、轻轻摆动；丑角笑开 |
| 13 | **强拍（第 4 小节）落回**，扬起一点木屑，然后拿着气球继续走 |
| 14.2 起 | 松手，气球飘走 |

## 梗怎么做
飘起 = `figureAdjust` 返回 `dy` + 小角度 `rotate`；气球线挂在 `ANCHORS.stand.handR` / `ANCHORS.walk.hand`。
