# 头像素材（换头接口）

把你的头像 PNG 通过 GitHub 网页上传到这里，下次让 Claude 运行 `npm run heads-check` 时会自动打包进预览页和成片。
**没有素材的档位会自动画原创占位头**，所以可以只传一部分。

## 规格

- 透明底 PNG，**1024×1024**
- **脖子根部对齐画布底边中点**（头像整体在画布中间偏上，脸大约占画布高度的一半）
- 朝向：人物在片中向右走，所以 `side`（侧脸）应**朝右**

## 文件名

| 路径 | 用途 |
| --- | --- |
| `A/side.png`、`A/three-quarter.png`、`A/front.png` | A 档（21–24 岁，第 1–4 站） |
| `B/…` | B 档（25–29 岁，第 5–9 站） |
| `C/…` | C 档（31–37 岁，第 10–14 站） |
| `D/…` | D 档（43–47 岁，第 15–16 站） |
| `<档位>/<场景id>.png`，例如 `A/s01.png`、`C/s11.png` | 某一站专用，优先级最高 |

场景 id：`intro`、`s01` … `s16`。

## 自动处理

没有专用版本时，素材会按该站画风自动处理：皮影站取剪影并叠镂空纹样；木刻 / 铜版 / 石版站提取线条后按刀刻排线重画；
水墨站转灰度后晕染；其余站按该站调色板做色调映射（素材里明显的红色会保留）。
效果可以在 `demo/<阶段>/heads_check.png` 里检查：四档 × 16 种画风的对照表。
