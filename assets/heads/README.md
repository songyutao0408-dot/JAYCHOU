# 头像素材（换头接口）

全片人物固定一个形象，头部只读这一张图：

| 路径 | 用途 |
| --- | --- |
| `three-quarter.png` | **全片唯一的头像**（已上传） |
| `<场景id>.png`，例如 `s11.png`、`intro.png` | 某一站专用，优先级最高（可选） |

场景 id：`intro`、`s01` … `s16`。没有 `three-quarter.png` 时自动画原创占位头。

## 规格

- 透明底 PNG，**1024×1024**
- **脖子底部对齐画布底边中点**
- 人物在片中向右走，脸朝右

替换或新增图片后，让 Claude 运行 `npm run heads-check`，会自动打包进预览页和成片，并生成对照表。

## 代码里的处理

- 以脖子底部为轴，整体**向下旋转约 12°**（下巴压低、视线平视前方），见 `src/rig/head.js` 的 `HEAD_TILT`
- 在身上的大小：1024 方框对应 145 个场景单位（`HEAD_BOX`），屏幕上约 157px
- 没有专用版本时，按该站画风自动处理：皮影站取剪影并叠镂空纹样；木刻 / 铜版 / 石版站提取线条后按刀刻排线重画；
  水墨站转灰度后晕染；其余站按该站调色板做色调映射（明显的红色会保留）。
  效果见 `demo/<阶段>/heads_check.png`：这张头像在 16 种画风下的对照表。
- 各站画风做好之前（占位阶段），片中头像保持原样，和身体肤色一致
