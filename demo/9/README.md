# 新结尾：歌名拼出头像（138 秒到全片结束，480p 30fps，无音轨）

| 时间 | 发生什么 |
| --- | --- |
| 138.0 – 142.0 s | 16 格专辑墙依次点亮 → 一行左一行右交错滑动 |
| 142.0 – 146.2 s | 卷成旋转圆环 |
| 146.2 – 146.7 s | 圆环缩成一个光点 |
| 146.7 – 146.9 s | 光点停顿半拍 |
| 146.9 – 150.8 s | 炸开成歌名四散，再分批聚拢，拼成侧脸、闭眼、一手扶耳的头像（约 4 秒） |
| 150.9 / 151.4 / 152.1 s | 下方依次浮出「27年，16张专辑，174首歌」「每一首歌都是我的青春」「谢谢你，JAY」（第三行更大、单独晚半拍） |
| 152.1 – 155.7 s | 头像和三行落款定格到全片结束 |

- 头像用的歌名：从用户清单前半部分挑出的 57 首 2–4 字歌名（每个带书名号），字块均匀，轮廓更像。《晴天》《夜曲》《七里香》放大加粗，四周留纸色描边，保证认得清。
- 明暗：每个字的深浅取它底下的明暗（头发、阴影密而深，脸颊亮部稀疏甚至留白），暗处再叠一层歌名；歌名落定时底下晕出一层很淡的赭色铅笔底色，把明暗托出来。
- 明暗图来自用户给的参考照片（只提交 220×174 的密度图 `src/data/portrait.js`，照片本身不进仓库；生成脚本 `tools/build-portrait.py`）。
