# 亮度与人物反差表

每站第 1–4 小节各截一帧（每小节第 3 拍）。

判定：平均亮度 ≥ 45% 合格，35–45% 注意，< 35% 不足（必须先调）；人物轮廓反差 ≥ 3 合格，2–3 注意，< 2 不足；轮廓贴色占比 > 30% 也要处理（加轮廓光或浅色描边）。
亮度 = 整幅画面 Rec.709 亮度的平均值。轮廓反差 = 沿人物边缘逐点，取边缘向内 6px 内（描边或身体）与外侧 3px 背景之间最大的相对亮度比（WCAG 算法），再取中位数；贴色 = 边缘上比值 < 1.5 的点所占比例。
