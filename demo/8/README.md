# 对拍后的全片小样（BGM：《爱在西元前》）

| 文件 | 内容 |
| --- | --- |
| `film_480p_30fps.mp4` | 全片 480p、30fps，**无音轨**（仓库里不放带版权歌曲的成片）。总时长 **148.09 秒** |

## 对拍结果

- **速度**：实测《爱在西元前》全曲稳定在 **126.80 BPM**（分段测量一致），`src/beat/config.js` 的 `BPM` 改为 126.8（用户确认）。每拍 0.4732 秒，每小节 1.8927 秒，每站 7.571 秒。画面内容不变，全部按拍换算。
- **第一拍**：`FIRST_DOWNBEAT = 0.459` 秒。歌里从 0.459 秒起每 4 拍一个重拍；音乐在 1.405 秒两拍弱起进来，2.352 秒第一下重拍落在 Intro 第 2 小节。
- **乐句对齐**：前奏到 13.71 秒结束，整个乐队进来，正好是**第 2 站开始的那一拍**；之后歌按 4 小节起伏，和每站 4 小节一致。
- **结尾**：音乐在视频结束（148.09 秒）时直接裁掉。结尾三行文案在 142.42 / 144.31 / 146.20 秒的强拍出现。

合成命令（音频文件不进仓库）：

```bash
node tools/render.mjs --height 480 --fps 30 --out demo/8/film_480p_30fps.mp4
node tools/mux-audio.mjs --video demo/8/film_480p_30fps.mp4 --audio 爱在西元前.mp3 --out render/film_480p_with_bgm.mp4
```
